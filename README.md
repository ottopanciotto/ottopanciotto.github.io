# Otto Panciotto

[Otto’s adventure journal](https://ottopanciotto.github.io/) — small monkey, big world.

A static HTML, CSS, and JavaScript website. Serve this directory over HTTP to preview it. No install or build step is needed.

Travel notes live in `data/travel.mjs`. Record the starting month and the readable date range; cross-year journeys appear once. Overlapping stops on the same route are combined, while repeat visits in different periods stay separate. Counts and filters are derived from these notes.

Run the content checks with `node --test tests/*.test.mjs`. The design guide is in `design-system/MASTER.md`. Font licenses are included in `assets/fonts/`.
